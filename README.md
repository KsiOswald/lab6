## Текст задачи



Разработать словарь, который сокращает строку до первого и последнего символа.

Также содержит метод, который на выход отдает первый и последний символы строки и переопределение метода ToString

Дочерний класс имеет новые методы - эффектиность сокращения("100-(2*100/Длину исходной строки)% 
И разворот строки - сложение 2-х символов в строку - последнего и первого.

## Задача 1



### Текст задачи


Реализовать Класс Time Поля hours и minutes типа данных byte и переопределить функцию сложения объекта типа Time и значения uint, вернуть Time.  


### Алгоритм решения



Класс Time имеет поля hours и minutes, а также 2 конструктора (по умолчанию и по значению), также свойства Hours и Minutes(в присвоении есть проверка на превышение 60)
Перегрузка операции сложения с двух обеих сторон.
Значение часов*60 + количество минут+количество минут, которые необходимо прибавить
Затем находятся минуты и часы
В оба направления функции идентичны, отличается только список входных параметров

### Алгоритм решения



Класс Time имеет поля hours и minutes, а также 2 конструктора (по умолчанию и по значению), также свойства Hours и Minutes(в присвоении есть проверка на превышение 60)
Также в классе перегружаются операции сложения, вычитания, инкримент, декримент, преобразование типов byte явно и bool неявно.
Перегрузка операции сложения описана в предыдущей задаче
Операция вычитания скалдывает часы*60 + количество минут - число минут пользователя
Происходит проверка на возможность выполенения операции
затем происходит вычисление часов и минут
Операция инкремент увеличивает минуту на 1, если минут становится 60, то происходит увеличение часов, минуты равны 0 (сменился час)
Операция дектримент уменьшает минуту на 1, если минут стало меньше 00, то час уменьшается на 1, минуты равны 0. Если и часы, и минуты равны 0, то вычитание не производится, возвращается 0 часов 0 минут

Преобразование типа Byte возвращает количество часов
преобразование типа Bool возвращает проверку времени на равенство 00:00
